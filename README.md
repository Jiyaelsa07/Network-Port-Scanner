
# 🔍 Network Port Scanner

A simple Python-based Network Port Scanner developed for cybersecurity learning and authorized network testing.

## 🚀 Features

- IP address and hostname resolution
- TCP port scanning
- Open port detection
- Basic service identification
- Custom port range selection
- Scan results summary
- Input validation

## 🛠️ Technologies Used

- Python 3
- Socket Library
- Kali Linux / Linux

## 📥 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Network-Port-Scanner.git
```

Navigate to the project folder:

```bash
cd Network-Port-Scanner
```

## ▶️ How to Run

Execute the scanner:

```bash
python3 scanner.py
```

Enter:
- Target IP address or hostname
- Starting port
- Ending port

## 🧪 Example

```text
NETWORK PORT SCANNER

Enter IP address or hostname: 127.0.0.1
Enter starting port: 1
Enter ending port: 1024

Target IP: 127.0.0.1

Scanning ports 1 to 1024...

SCAN RESULTS
Open ports: 1
Other ports: 1023
Scan completed.
```

*Example output only. Actual results depend on the target.*
